# 🌤️ Modern Weather Dashboard

A responsive, location-aware weather dashboard built with **C#** and **ASP.NET Core Razor Pages**. This application features a sleek glassmorphism user interface and pulls real-time weather data and 24-hour forecasts using the OpenWeatherMap API.

## ✨ Features

* **Real-Time Weather:** Displays current temperature, humidity, wind speed, and "feels like" temperature.
* **Auto-Geolocation:** A built-in location button (📍) requests the user's browser coordinates to automatically fetch local weather without typing.
* **Smart Timezones:** Calculates and displays the accurate local time and date for any searched city worldwide.
* **24-Hour Forecast:** A horizontally scrolling timeline showing weather conditions, temperature, and rain probability (💧) in 3-hour intervals.
* **Glassmorphism UI:** A modern, frosted-glass design aesthetic using CSS backdrop filters and responsive CSS Grid logic.

## 🛠️ Tech Stack

* **Backend:** C#, ASP.NET Core 8.0, Razor Pages
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (for Geolocation)
* **API:** OpenWeatherMap API
* **Data Parsing:** Newtonsoft.Json
